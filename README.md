# Story Stick

Online woodworking calculators for the bench: board feet, layout, joinery, and wood movement.

## Tools

### Cabinets
- Kitchen planner
- Cabinet box (plywood box, face frame, doors / drawers)
- Cabinet doors (overlay, reveal, inset, hinges, and shaker frame if you want one)
- Drawer fronts & boxes

### Shop
- Board feet
- Measure converter (fractions / decimal / mm)
- Even spacing
- Miter & polygons
- Dovetail layout
- Wood movement
- Circle & segments
- Weight estimator

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` deploy on Vercel.
