# Story Stick

Online woodworking calculators for the bench: board feet, layout, joinery, and wood movement.

## Tools

- Board feet
- Measure converter (fractions / decimal / mm)
- Even spacing
- Miter & polygons
- Dovetail layout
- Wood movement
- Circle & segments
- Weight estimator

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` deploy on Vercel.
